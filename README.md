# Dodla's Tours & Travels

> **Yatra Specialists Since 1962 | Vijayawada, Andhra Pradesh**

Dodla's Tours & Travels is Andhra Pradesh's premier devotional travel institution. Curated sacred yatras across India's most venerated shrines with authentic satvik food, luxury AC transport, tranquil sanctuary stays, and heartfelt senior citizen care.

---

## 🌟 Key Features
- **Modern Responsive Design**: Vibrant saffron & deep navy theme built with Bootstrap 5 and custom CSS.
- **Cinematic Hero Carousel**: Dynamic auto-sliding background showcase of sacred destinations with interactive dots and live counter.
- **Find Your Yatra (Quick Search)**: Interactive package finder with one-click WhatsApp consultation.
- **Sacred Journeys Showcase**: Curated itineraries including 108 Divya Desam, Uttarakhand Chardham, Amarnath & Kashmir, Kailash Manasarovar, Ganga Sagar, Muktinath Nepal, and Sri Lanka Ramayana Trail.
- **Interactive Trust Counters**: Heritage metrics animated dynamically on scroll.
- **Direct WhatsApp Concierge**: Instant booking and inquiry integration directly with Vijayawada Head Office.

## 🚀 Running Locally
To launch a local development server:

```bash
# Using Python
cd "Dodla's tours/www.dodlastoursandtravels.in"
python -m http.server 8080
```

Open your browser at [http://localhost:8080](http://localhost:8080).
